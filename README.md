# Amira Tent Multipage Website

Static multipage redesign concept for Amira Tent.

## Pages
- `index.html` — Beranda
- `produk.html` — katalog produk
- `detail-tenda-roder.html` — detail Tenda Roder
- `proyek.html` — galeri dengan filter & lightbox
- `harga.html` — referensi harga
- `tentang.html` — profil
- `kontak.html` — formulir quotation ke WhatsApp

## Run locally
Open `index.html` directly, or serve the folder with any static HTTP server.

## Important
The demo references Amira Tent portfolio images from existing public Amira Tent URLs. Before production deployment, copy approved original images into a local `/assets/images/` directory and update image paths so the site does not hotlink external assets. Confirm current pricing, phone numbers, addresses, product claims, and project descriptions before launch.
